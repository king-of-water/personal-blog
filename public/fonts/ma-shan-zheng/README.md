# Personal verse font

Ma Shan Zheng, by The Ma Shan Zheng Project Authors.

Source: https://github.com/google/fonts/tree/main/ofl/mashanzheng

`personal-verse.ttf` is the Google Fonts text subset for:

人生居天壤间忽如飞鸟栖枯枝我今隐约欲何为

It is self-hosted and only used by the personal page verse. If the verse changes,
regenerate the subset to include the new characters. The font is distributed
under the SIL Open Font License 1.1; see `OFL.txt`.
